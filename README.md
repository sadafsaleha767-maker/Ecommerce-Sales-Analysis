# E-commerce Sales Analysis

## 📊 Project Overview

This project analyzes e-commerce sales data using Microsoft Excel.

The goal of this project is to clean raw sales data, analyze business performance, create interactive dashboards, and generate useful business insights.

## 🛠️ Tools & Skills

- Microsoft Excel
- Data Cleaning
- Data Analysis
- Pivot Tables
- Data Visualization
- Dashboard Creation
- Business Insights

## 📁 Project Structure

The Excel workbook contains the following sheets:

- Raw_Data
- Cleaned_Data
- Analysis
- Pivot_Table
- Dashboard
- Insights

## 📈 Key Analysis

The project analyzes:

- Total Sales
- Total Profit
- Quantity Sold
- Average Order Value
- Profit Margin
- Category-wise Sales
- Product-wise Sales
- City-wise Sales
- Category-wise Profit

## 💡 Key Insights

- Identified the highest-performing sales categories.
- Analyzed sales performance across different cities.
- Identified top-selling products.
- Evaluated profit and sales performance.
- Created a dashboard for easy business performance tracking.

## 📊 Dashboard

The project includes an Excel dashboard that presents important sales and profit metrics through charts and visualizations.
